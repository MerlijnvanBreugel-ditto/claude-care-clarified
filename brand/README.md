# Ditto Care — Brand Workspace

Everything that defines how Ditto looks, sounds, and feels.

The current brand direction (Mar 2026) is photography-forward, editorial, and premium — a maturation from the earlier playful/illustration-first identity in the brandbook v2. The consumer deck represents the most up-to-date expression.

## Structure

```
brand/
├── strategy/
│   ├── positioning.md          — mission, manifest, proposition, vision, segments
│   ├── narrative.md            — full pitch story arc, key phrases, deck comparison
│   └── values-and-culture.md   — 5 brand values, culture principles, personality
├── visual-design/
│   ├── color-system.md         — current palette + legacy reference
│   ├── typography.md           — web (Bricolage + Inter) and print (Uncut Sans)
│   ├── graphic-elements.md     — photography style, flexible O, illustrations, logo
│   └── brand-evolution.md      — what changed, what carried forward, what to formalize
├── voice-and-tone/
│   └── brand-voice.md          — voice principles, writing rules
├── decks/
│   └── consumer-layer-deck.html — investor/pitch deck (Mar 2026, current brand expression)
└── assets/
    ├── Ditto_Brandbook_v2.pdf  — historical reference (early 2025, largely outdated)
    └── logo/
```
