# Color System

## Current Palette

| Color | Hex | Role |
|---|---|---|
| **Brand Navy** | `#0D164F` | Primary brand color, dark backgrounds, default text |
| **Teal Blue** | `#58B6D2` | Primary accent, emphasis |
| **Gold** | `#D4A832` | Positive highlights, warmth (light backgrounds) |
| **Light Blue** | `#7DD4E8` | Accent on dark/photo slides — calm, confident |
| **Red** | `#D94F4F` | Negative, pain, problems |
| **Soft BG** | `#F7F6F3` | Light slide/section backgrounds |
| **Text Light** | `#7C8297` | Secondary text, captions |

## Color Logic

- **Red** = negative, pain, problems (e.g., "2008", "hate it")
- **Gold** = positive, cheerful, warmth (e.g., "love it", "works")
- **Teal Blue** = accent, emphasis, feature highlight
- **Light Blue** = accent on dark backgrounds (replaces yellow at headline scale)
- **Brand Navy** = default
