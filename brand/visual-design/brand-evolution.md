# Brand Evolution

## Where we came from (Brandbook v2, early 2025)
- Pastel gradients (mint-to-teal, mint-to-yellow)
- Illustration-first: line drawings, faceless characters, gradient fills
- Bright, playful, startup-friendly aesthetic
- Tagline: "Less hassle. Better healthcare."
- Typography: Uncut Sans
- No photography guidelines

## Where we are now (Mar 2026)
- Photography-forward: editorial, warm, film-grain quality
- Real people in real settings — connection, dignity, life moments
- Calmer, more premium, more confident
- Tagline: **"Care. Clarified."**
- Color palette matured: semantic color logic, gold for warmth, red for pain
- Navy as the anchor, photography does the emotional work
- Typography: Bricolage Grotesque (headings) + Inter (body) for web

## What carried forward
- Navy (`#0D164F`) as the anchor
- Teal (`#58B6D2`) as the primary accent
- The flexible 'o' as a brand element
- Clear, direct, empathetic tone
- Privacy-by-architecture positioning

## What was retired
- Pastel gradients as a primary visual tool
- "Less hassle. Better healthcare." tagline
- Illustration as the default visual language for external comms
- `#F3DE70` yellow at large/headline scale (still valid for UI buttons/small text)

## Still to formalize
1. **Photography guidelines** — codify the editorial style (warmth, real people, film quality, life moments)
2. **Illustration role** — likely in-app/product only, not external brand
3. **Web typography** — Bricolage Grotesque + Inter as the official web stack
4. **New colors** — gold (`#D4A832`), light blue (`#7DD4E8`), red (`#D94F4F`) need to be added to official palette
5. **Yellow's role** — UI-only, not brand-level accent
