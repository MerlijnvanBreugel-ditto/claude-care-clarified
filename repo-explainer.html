About This Repo

What You're Looking At

This is the Ditto Productivity Powerhouse — an interactive map of Mewtwo, Ditto Care's AI-powered PM co-pilot. It shows every command, workflow, agent, integration, and knowledge artifact that powers our product development process.

How It Works

  • Commands (/refine-idea, /scope-feature, etc.) are the entry points. Type them in Claude Code to trigger workflows.
  • Workflows are multi-step processes that produce artifacts (specs, tickets, mockups).
  • Agents are specialists (product-designer, user-researcher) dispatched by Mewtwo when their tools are needed.
  • Context files are the knowledge base — product strategy, brand positioning, design system references.

How to Contribute

  • Add new workflows in pm-workspace/workflows/
  • Add new commands in pm-workspace/commands/
  • Always update registry/registry.json when creating artifacts
  • Spot something missing? Add it to backlog/backlog.json
  • Regenerate this page: node scripts/generate-dashboard.mjs

Rules of the Game

🎯Solve real problems. Every feature must answer: what problem, for whom, how painful?
✂️Less is more. A sharp 5-line spec beats a 50-line novel.
📊Data over opinion. Prefer evidence. When intuition leads, validate cheaply.
🔍Multi-perspective rigor. Every spec gets stress-tested from 6 angles: user, dev, strategy, growth, business, privacy.
🔄Self-improving. Feedback loop after every workflow. Learnings get captured.

Anti-Patterns

Ship without tracking. Nothing goes out without measurement tickets. No exceptions.
Skip multi-perspective review. Every spec gets reviewed from 6 lenses before it's "done."
Build features nobody asked for. Start with evidence, not assumptions.
Write documentation nobody reads. If it's longer than it needs to be, cut it.
