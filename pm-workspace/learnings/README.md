# Learnings Directory

This directory contains Mewtwo's self-reflections and improvement logs.

## Format

Each learning is a markdown file named `YYYY-MM-DD-[topic].md` with:

```markdown
# Learning: [Title]

**Date**: YYYY-MM-DD
**Workflow**: [Which workflow triggered this]
**Trigger**: [What went wrong or what feedback was given]

## What Happened
[1-2 sentences]

## Why It Went Wrong
[Root cause — not just symptoms]

## Rule Going Forward
[Specific, actionable rule to follow next time]

## Skill Impact
[Should this change a workflow definition? If yes, which one and how?]
```

## Positive Reinforcements

When Merlijn confirms "you were perfect", log what worked:

```markdown
# Reinforcement: [Title]

**Date**: YYYY-MM-DD
**Workflow**: [Which workflow]
**What Worked**: [Specific behavior or approach that was validated]
```
