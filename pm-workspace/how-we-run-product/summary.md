# How We Run Product — Local Reference

> Source: [Confluence](https://dittocare.atlassian.net/wiki/spaces/DG/pages/821919746/How+We+Run+Product)

## Structure
Strategy → Discovery → Ship & Release → Experimentation & Learning → feeds back into Strategy

## Weekly Product Cadence (Thursday, 30 min)
1. **Learning** (10 min) — evaluate shipped features (Week 1/2 checks), new insights
2. **Roadmap Update** (15 min) — next 6-ish weeks, prioritize new ideas (Explore/Exploit + RISCE)
3. **Delivery Excellence** (5 min) — release deadlines, impediments

## Post-Launch Evaluation
- **Week 1 Health Check**: tracking ok? bugs? early adoption? feedback?
- **Week 2 Impact Check**: hit success criteria? behavior change? root cause if miss?
- **Learning Log**: Hypothesis → Result → Why → Next
- Verdicts: Double down / Iterate / Deprioritize / Done

## Anti-Patterns to Watch
- Ship ≠ done (shipping is the beginning)
- No success hypothesis = can't measure
- Celebrate impact, not releases
- 0% kill rate = not taking real bets
