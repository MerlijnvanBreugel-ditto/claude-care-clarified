# How We Run Product

> Last updated: 2026-02-19

This is how Ditto's product team operates — from strategy to shipping. Every page exists to make decisions faster and outcomes clearer. If a page doesn't help you do your job, fix it or flag it.

## Structure

| Section | Question it answers | Link |
|---|---|---|
| **Product Strategy** | What do we build and why? | [product-strategy/](./product-strategy/) |
| **Discovery** | How do we understand user needs? | [discovery/](./discovery/) |

| **Experimentation & Learning** | How do we iterate on shipped features? | [experimentation-and-learning/](./experimentation-and-learning/) |

## How these connect

```
Strategy (what to build) → Discovery (validate the problem)
    → Ship & Release (activate users, communicate)
        → Experimentation & Learning (measure impact, iterate)
            → Learning feeds back into Strategy
```
