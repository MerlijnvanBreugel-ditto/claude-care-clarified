# Mobbin Research: Medication Reminder UI Inspiration

**Date**: 2026-02-02
**Research Focus**: Medication adherence apps, reminder UI patterns, caregiver visibility, gamification

---

## 1. Medication Adherence App Patterns

### Key Competitors Analyzed

| App | Key Strength | Inspiration For |
|-----|--------------|-----------------|
| **Medisafe** | Medfriend caregiver alerts | Direction A: Caregiver visibility |
| **MyTherapy** | Health journal integration | Direction A: Adherence tracking |
| **Mango Health** | Gamification, points system | Direction B: Gamified approach |
| **Round Health** | Beautiful, minimal design | Direction C: Wellness aesthetic |
| **Pill Reminder** | Simple, clear reminders | Direction A: Core reminder pattern |

### Common Patterns Observed

**Reminder Notification Patterns:**
1. **Time-based prominence**: Large time display, medication name secondary
2. **Action-first buttons**: "Take Now" always primary action
3. **Snooze options**: "Remind in 15/30/60 min" common
4. **Skip with friction**: "Skip" requires confirmation or reason

**Adherence Dashboard Patterns:**
1. **Weekly view**: 7-day dot/bar visualization
2. **Percentage prominent**: "92% adherence" as hero metric
3. **Streak counters**: Days in a row without missed dose
4. **Next dose countdown**: "Next in 4h 23m"

**Caregiver Features:**
1. **Missed dose alerts**: Push notification to caregiver
2. **Adherence reports**: Shareable summaries
3. **Family management**: Multiple profiles in one app
4. **Privacy controls**: What data is visible

## 2. Gamification Patterns (Direction B Inspiration)

### Mango Health Approach
- Points for each dose taken on time
- Bonus points for streaks
- Redeemable rewards (gift cards)
- Leaderboards (optional)

### Medisafe Gamification
- Adherence percentage as "score"
- Weekly challenges
- Achievement badges
- Social comparison (optional)

### Relevant for Ditto
- Streak counters create loss aversion
- Visual progress (rings, bars) feel rewarding
- Avoid childish game mechanics (target adult chronic patients)
- Caregiver visibility adds social accountability

## 3. Wellness-Focused Medication Apps (Direction C Inspiration)

### Round Health (Design-Forward)
- Clean, minimal interface
- Large touch targets
- Soft colors, no clinical feel
- Medication as "daily ritual"

### Pill Reminder (Simple)
- Single-purpose clarity
- No feature bloat
- Quick in-and-out

### Calm/Headspace Influence
- What if medication felt like self-care?
- Reframe: "Morning ritual" not "8 AM pills"
- Warm colors, soft typography
- Breathing/pause moment before confirmation

## 4. Synthesis: Three Design Directions

### Direction A: On-Brand (Ditto-Native)
**Inspiration**: Medisafe + MyTherapy
- Strict adherence to Ditto design system
- Card-based layouts
- Navy primary, yellow accents
- Tab bar visible
- Clinical but friendly

### Direction B: Partly On-Brand (Gamified)
**Inspiration**: Mango Health + Streaks apps
- Ditto colors preserved
- Progress rings, streak badges
- Achievement system
- Encouraging copy
- Caregiver connection visible

### Direction C: Experimental (Wellness)
**Inspiration**: Round Health + Calm
- Full-screen immersive
- Warm gradient backgrounds
- Medication as "self-care ritual"
- Serif typography for warmth
- No clinical language
