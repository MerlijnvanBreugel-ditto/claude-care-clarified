# Care Circle V2

> **"Polarsteps for Healthcare"** — Keeping loved ones in the loop on your healthcare journey

## Overview

Care Circle V2 transforms how patients share their health journey with loved ones. Unlike WhatsApp messages that feel ephemeral, Care Circle creates meaningful **assets** (cards, updates, profiles) that show care and commitment.

## V2 Feature Scope

### Included
| Feature | Description |
|---------|-------------|
| Invitation cards | Spotify-style shareable cards (not just links) |
| Personal context | "How I'm really doing" notes with updates |
| Short summary option | Customizable detail level per share |
| Simple reactions | ❤️ 🤗 💪 emoji reactions |
| Support cards | Digital get-well cards using same card mechanism |
| Help offers | Structured way to offer practical support |
| Profile page | Bio, FAQ, context for followers |
| Timeline overview | Clear view of own/followed journeys |

### Descoped (V3)
- Per-person sharing controls
- Groups/Circles (inner/outer)
- Shared calendar/tasks
- Status indicator ("Today I'm...")
- Message threading

## Design Principles

1. **Assets > Messages** — Creating something = commitment + meaning
2. **Social Proof** — "40% already share..." builds trust
3. **Commitment/Intention** — Ask "why?" before enabling action
4. **One-to-Many** — Share to all followers (not per-person)
5. **Reusable Cards** — Same mechanism for invites and reactions
